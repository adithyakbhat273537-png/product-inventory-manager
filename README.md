
# Product Inventory Manager

A browser-based Product Inventory Manager developed using
TypeScript, HTML, and CSS. This project demonstrates basic
TypeScript concepts through a practical inventory application.

## Features

- Display a list of products
- Add new products
- Search products by name or tag
- Track available and out-of-stock products
- Apply a 10% discount to product prices
- Delete products
- Display total and available product counts
- Responsive user interface

## Technologies Used

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/product-inventory-manager.git
cd product-inventory-manager
```

### 2. Install dependencies

```bash
npm install
```

### 3. Compile TypeScript

```bash
npx tsc
```

The compiled JavaScript files will be generated in the
`dist` directory.

### 4. Run the application

Open the project using Visual Studio Code and launch
`index.html` with the Live Server extension.

## Deployment

This project can be hosted using GitHub Pages.

1. Push the project to a GitHub repository.
2. Open Settings in the repository.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch and `/(root)` folder.
6. Save and wait for deployment.
